Обычные HTML, CSS и немного JavaScript, без сборки. Розы, перо и разделитель
отрендерены в Blender скриптом [`blender/rose.py`](https://github.com/Veeva61/Veeva61/tree/main/blender)
из репозитория профиля; змейка в разделе «Активность» собирается там же,
в [`snake/snake.py`](https://github.com/Veeva61/Veeva61/tree/main/snake).

Посмотреть локально:

```bash
python -m http.server 8000
```

и открыть http://localhost:8000.
